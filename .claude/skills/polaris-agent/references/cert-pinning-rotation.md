# Server cert pinning and dual-pin rotation

Verbatim from CLAUDE.md → Deployment & Updates, plus the dual-pin paragraph from ARCHITECTURE.md → Multi-process architecture.
The Polaris Agent's leaf-cert pinning: `getServerCertFingerprint()` in [src/services/certInfo.ts](src/services/certInfo.ts) reads `POLARIS_PROXY_CERT_PATH` and computes the same SHA-256 nginx serves. The fingerprint stamps `agent.conf` at install time; the Go agent's `pinned.VerifyPeerCertificate` validates against it on every connection.

**Dual-pin cert rotation** (rotation without fleet-wide agent re-install): each `ManagedAgent` row carries `serverCertFingerprint` (canonical pin) plus `additionalServerCertFingerprints String[]` (staged pins). Enroll cross-check accepts ANY pin in the union; `/agents/config` ships the union to the agent on every poll; the Go agent's `pinned.VerifyPeerCertificate` matches the presented cert against the SET. Operator-driven rotation lives on Server Settings → Maintenance → Polaris Agent → "Cert pin rotation": **stage** a new pin → server pushes to every agent + WS refresh-config → agent saves agent.conf + exits via `os.Exit(0)` so systemd cycles it with the new pin set → rotate the server cert (nginx reload) → wait for every agent to heartbeat post-rotation → **retire** the old pin. The agent.conf format gained a `cert_fingerprints = pin1,pin2,...` line; the legacy `cert_fingerprint = <canonical>` line stays for pre-dual-pin binary downgrade safety. Routes: `GET /server-settings/agents/cert-pins/summary`, `POST /server-settings/agents/cert-pins/bulk-add`, `POST /server-settings/agents/cert-pins/bulk-remove`. Bulk-remove of a pin that would leave any agent with zero pins is skipped for that agent (returns `lastPinSkipped: N`). See polaris-agent → cross-cutting-polaris-agent.md "Cert pin rotation" for the full lockstep checklist.

## Dual-pin (from ARCHITECTURE.md → Multi-process architecture)

**Phase 2 dual-pin** lifts the "fleet-wide re-install on every cert rotation" caveat. Each `ManagedAgent` row carries `serverCertFingerprint` (canonical) + `additionalServerCertFingerprints String[]` (staged). The union is the agent's trust set; rotation is operator-driven via the Maintenance card's "Cert pin rotation" pane (`POST /server-settings/agents/cert-pins/bulk-add` and `/bulk-remove`). The agent.conf format gained `cert_fingerprints = pin1,pin2,...` (Go agent parses the union; pre-Phase-2 binaries still read the legacy `cert_fingerprint` line for downgrade safety). When the operator stages a new pin, the server pushes via WS `refresh-config` and online agents apply within seconds (offline agents pick it up on next /config poll); agents Save() the new pin set + exit via `os.Exit(0)` so systemd cycles the process with the new pin set live. See polaris-agent → cross-cutting-polaris-agent.md "Cert pin rotation" for the full lockstep checklist.
